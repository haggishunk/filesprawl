# Design: Migrate to Cobra CLI Framework

## Overview
This change replaces the manual flag parsing and command dispatch in `main.go` with the Cobra CLI framework, providing professional help generation, better error messages, and modern CLI patterns.

## Current vs Proposed Structure

### Current (Manual)
```
main.go
├── main()
├── run()
├── runCommand() - switch statement
├── parseIndexArgs() - manual flag parsing
├── parseDuplicatesArgs() - manual flag parsing
├── runListRemotes()
├── runIndex()
└── runDuplicates()
```

### Proposed (Cobra)
```
main.go
└── main() - execute root command

cmd/
├── root.go - root command
├── list_remotes.go - list-remotes subcommand
├── index.go - index subcommand
├── duplicates.go - duplicates subcommand
└── completion.go - auto-generated by Cobra

internal/
└── ... (existing packages remain unchanged)
```

### List Remotes Command
```go
// cmd/list_remotes.go
var listRemotesCmd = &cobra.Command{
    Use:   "list-remotes",
    Short: "List configured rclone remotes",
    Long: `List all rclone remote names as configured in the active local
rcd session running on http://localhost:5572.`,
    Example: `  filesprawl list-remotes`,
    RunE: func(cmd *cobra.Command, args []string) error {
        return runListRemotes(cmd.Context(), cmd.OutOrStdout())
    },
}
```

### Index Command
```go
// cmd/index.go
var indexCmd = &cobra.Command{
    Use:   "index",
    Short: "Index files from a remote storage location",
    Long: `Index all files from the specified remote, computing hashes and
persisting metadata to the database.`,
    Example: `  # Index entire remote
  filesprawl index --remote media

  # Index specific path within remote
  filesprawl index --remote media --path code/flux`,
    PreRunE: validateIndexArgs,
    RunE: func(cmd *cobra.Command, args []string) error {
        // Get flag values from cmd
        remote, _ := cmd.Flags().GetString("remote")
        path, _ := cmd.Flags().GetString("path")
        
        // Call existing business logic
        return runIndex(cmd.Context(), indexArgs{
            Remote: remote,
            Path:   path,
        }, cmd.OutOrStdout())
    },
}

func init() {
    indexCmd.Flags().StringP("remote", "r", "", "remote name (required)")
    indexCmd.Flags().StringP("path", "p", "", "path within remote")
    indexCmd.MarkFlagRequired("remote")
}
```

### Duplicates Command
```go
// cmd/duplicates.go
var duplicatesCmd = &cobra.Command{
    Use:   "duplicates",
    Short: "Find duplicate files",
    Long: `Find files with identical content hashes, either within a single
remote or across all indexed remotes.`,
    Example: `  # Find duplicates within a remote
  filesprawl duplicates --remote media

  # Find duplicates across all remotes
  filesprawl duplicates --across-remotes

  # Find large duplicates (>10MB)
  filesprawl duplicates --remote media --min-size 10485760

  # Filter by hash type and limit results
  filesprawl duplicates --across-remotes --hash-type sha256 --limit 20`,
    PreRunE: validateDuplicatesArgs,
    RunE: func(cmd *cobra.Command, args []string) error {
        // Get all flag values
        remote, _ := cmd.Flags().GetString("remote")
        acrossRemotes, _ := cmd.Flags().GetBool("across-remotes")
        hashType, _ := cmd.Flags().GetString("hash-type")
        minSize, _ := cmd.Flags().GetInt64("min-size")
        limit, _ := cmd.Flags().GetInt("limit")
        offset, _ := cmd.Flags().GetInt("offset")
        
        return runDuplicates(cmd.Context(), duplicatesArgs{
            Remote:        remote,
            AcrossRemotes: acrossRemotes,
            HashType:      hashType,
            MinSize:       minSize,
            Limit:         limit,
            Offset:        offset,
        }, cmd.OutOrStdout())
    },
}

func init() {
    duplicatesCmd.Flags().StringP("remote", "r", "", "find duplicates within this remote")
    duplicatesCmd.Flags().Bool("across-remotes", false, "find duplicates across all remotes")
    duplicatesCmd.Flags().String("hash-type", "", "filter by hash type (md5, sha1, sha256, dropbox)")
    duplicatesCmd.Flags().Int64("min-size", 0, "minimum file size in bytes")
    duplicatesCmd.Flags().Int("limit", 0, "maximum number of duplicate groups to return")
    duplicatesCmd.Flags().Int("offset", 0, "skip this many duplicate groups")
}

func validateDuplicatesArgs(cmd *cobra.Command, args []string) error {
    remote, _ := cmd.Flags().GetString("remote")
    acrossRemotes, _ := cmd.Flags().GetBool("across-remotes")
    
    // Mutually exclusive validation
    if remote != "" && acrossRemotes {
        return errors.New("--remote and --across-remotes are mutually exclusive")
    }
    if remote == "" && !acrossRemotes {
        return errors.New("must specify either --remote or --across-remotes")
    }
    
    // Hash type validation
    hashType, _ := cmd.Flags().GetString("hash-type")
    if hashType != "" {
        validTypes := map[string]bool{"md5": true, "sha1": true, "sha256": true, "dropbox": true}
        if !validTypes[hashType] {
            return fmt.Errorf("invalid hash type %q, must be one of: md5, sha1, sha256, dropbox", hashType)
        }
    }
    
    return nil
}
```

## Shell Completion

### Bash
```bash
# Generate completion script
filesprawl completion bash > /etc/bash_completion.d/filesprawl

# Or for user-level:
filesprawl completion bash > ~/.local/share/bash-completion/completions/filesprawl
```

### Zsh
```zsh
# Generate and load
filesprawl completion zsh > "${fpath[1]}/_filesprawl"
```

### Fish
```fish
# Generate and load
filesprawl completion fish > ~/.config/fish/completions/filesprawl.fish
```

With completion installed, users get:
- Command name completion
- Flag name completion
- Flag value suggestions (where applicable)

## Migration Strategy

### Phase 1: Add Cobra Structure (No Breaking Changes)
1. Add Cobra dependency
2. Create cmd/ directory with command files
3. Keep existing functions working
4. Main.go calls Cobra, Cobra calls existing functions

### Phase 2: Enhance (Optional Future Work)
- Add command aliases (e.g., `dups` for `duplicates`)
- Add persistent flags (e.g., `--database-url` on root)
- Add interactive prompts for missing required flags
- Add config file support via viper

## Benefits Summary

### For Users
- **Better Discovery**: `--help` on any command shows usage
- **Faster Learning**: Examples in help output
- **Less Frustration**: Clear error messages with suggestions
- **Shell Integration**: Tab completion for commands and flags
- **Consistency**: Familiar patterns from kubectl, docker, gh, etc.

### For Developers
- **Less Code**: Cobra handles parsing, validation, help generation
- **Easier Maintenance**: Each command in its own file
- **Better Testing**: Cobra provides testing utilities
- **Standard Patterns**: Follow established Go CLI conventions
- **Easier Extension**: Adding new commands is straightforward

## Implementation Notes

- Keep all existing business logic (`runListRemotes`, `runIndex`, `runDuplicates`) unchanged
- Move validation from parse functions to Cobra's `PreRunE` hooks
- Use Cobra's built-in flag validation where possible
- Maintain backward compatibility - all existing command syntax continues to work
- Tests should pass without modification (business logic unchanged)
